# MarketPro

## About

MarketPro is a simple marketing agency website built with HTML, CSS, and JavaScript. The goal of this project was to practice building a responsive landing page with a clean layout and easy navigation.

The website includes the main sections that you would expect on a marketing agency site, such as services, portfolio, testimonials, and a contact section.

---

## Features

- Responsive design
- Modern landing page
- Smooth scrolling navigation
- Services section
- Portfolio section
- Testimonials
- Contact section
- Hover effects on buttons and cards
- Works on desktop and mobile devices

---

## Built With

- HTML5
- CSS3
- JavaScript

---

## How to Run

1. Download or clone the project.
2. Open the project folder.
3. Open `index.html` in your browser.

No installation or extra tools are needed.
