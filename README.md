# MarketPro

A responsive digital marketing agency website built using HTML, CSS, and JavaScript. The project demonstrates the creation of a modern landing page with clean UI, responsive design, and interactive elements.

---

## Overview

MarketPro is a front-end website for a fictional digital marketing agency. It was created to practice responsive web design, semantic HTML, CSS styling, and basic JavaScript functionality.

The website presents information about the agency, highlights its services, showcases previous work, displays client testimonials, and allows visitors to contact the company through a simple contact form.

---

## Features

- Responsive layout for desktop, tablet, and mobile devices
- Sticky navigation bar
- Smooth scrolling navigation
- Hero section with a call-to-action button
- Services section
- Why Choose Us section
- Portfolio section
- Client testimonials section
- About Us section
- Contact form with JavaScript validation
- Hover animations on cards and buttons
- Dynamic navigation bar color on scroll

---

## Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JavaScript)

## How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Double-click `index.html`, or open it using any modern web browser.

No installation, build tools, or external dependencies are required.

## Website Sections

### Home
A hero section introducing the agency with a clear call-to-action button.

### Services
Highlights the main services offered by the agency, including SEO, social media marketing, branding, online advertising, content creation, and analytics.

### Why Choose Us
Explains the advantages of choosing MarketPro, including experience, creativity, affordable pricing, and customer support.

### Portfolio
Displays example marketing projects completed for different clients.

### Testimonials
Shows feedback from previous clients to demonstrate credibility.

### About
Provides information about the agency, its mission, and its approach to digital marketing.

### Contact
Includes a contact form with JavaScript validation to ensure all required fields are completed before submission.
